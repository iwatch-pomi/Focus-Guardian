# Focus Guardian

**フォーカス・ガーディアン** — AIとデバイスの力で「集中力」を守り抜くライフ・オペレーティングシステム。

> 日常の「いつの間にか消えていく時間」を、可視化されたリソースに変える。

---

## コンセプト

| 価値 | 説明 |
|------|------|
| 自動記録 | 5〜15分おきのインターバルスナップショットで、手動不要のタイムトラッキング |
| プライバシー保護 | エッジAI処理 → 生画像は即時破棄。外部送信なし |
| テクニカル分析 | タイムドローダウン・ボラティリティ通知・エネルギーマッピングで集中を数値化 |

---

## 主要機能

### A. センシング・入力
- **インターバル認識**: 5〜15分ごとにスナップショット → AIが行動ラベルを自動生成
- **マルチモーダル判定**: 画像 + 環境音 + デバイスセンサーで認識精度を最大化
- **プライバシーゲートキーパー**: PIRセンサーで人の存在を検知した時のみカメラ起動

### B. 分析・インテリジェンス
- **タイムドローダウン**: 集中が途切れてから復帰するまでの停滞時間を計測
- **ボラティリティ通知**: 脱線を検知した瞬間のリアルタイム警告
- **エネルギーマッピング**: 姿勢・音から集中度・疲労度を数値化
- **未来予測**: 過去パターンから浪費が発生しそうな時間帯を事前警告

### C. 出力・ソーシャル
- **抽象化レンダリング**: ログは3Dアバター・ドット絵に変換（生画像を保存しない）
- **タイムベンチマーク**: 匿名化された他ユーザーデータと比較

## セットアップ

### 必要環境
- Python 3.11+
- Node.js 20+
- Anthropic API キー（エッジAI推論用）

### バックエンド

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env  # ANTHROPIC_API_KEY を設定
uvicorn api.main:app --reload
```

### フロントエンド

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```

## プライバシー設計

```
カメラ起動
  ↓ PIRセンサーが人の存在を確認した場合のみ
スナップショット撮影（メモリ上のみ）
  ↓ エッジAIで即時解析（Claude Vision API / ローカルモデル）
行動ラベル生成（テキストのみ保存）
  ↓
生画像を即時破棄 ✓
```

生の画像・音声データは一切ディスクに保存されません。
